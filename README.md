# কিভাবে কাজ করে? 
এটি জাভা স্ক্রিপ্ট এর মাধ্যমে ব্রাউজার থেকে ক্যামেরা লোকেশন এবং মাইক্রোফোনের পারমিশন নেই ভিকটিমের থেকে এবং ভিকটিমকে একটি ভুয়া ওয়েবপেজ দেখায় এবং গোপনে গোপনে তার পিছন ক্যামেরা দিয়ে তোলা ছবি লাইভ পাঠাতে থাকে এবং তার লোকেশন গুগল ম্যাপ এর লিংক সহ পাঠিয়ে দেয় এবং তার ভয়েস কিছু সেকেন্ড পর পড়ে আপডেট দেয় এসবগুলো একটি ফোল্ডারে জমা হয়।
